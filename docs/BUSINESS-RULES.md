# 抢购与寄售业务规则

本文记录 2026-10 按《小程序修改内容》落地的业务规则，以及实现时采用的假设。所有时间均按**北京时间（UTC+8）**计算，与服务器所在时区无关。

## 可配置项（管理后台 → 内容配置 → business）

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `grabStart` / `grabEnd` | 09:30 / 09:35 | 每日抢购时间，设置一次每天生效 |
| `consignStart` / `consignEnd` | 14:30 / 17:30 | 每日寄售时间（原文档写作「2:30—5:30」，按下午理解；可随时改） |
| `grabLimit` | 2 | 每人每次（每个抢购日）最多成功抢到的单数 |
| `fuelRate` | 2 | 燃料费比例（%），抢购成功时按售价扣除 |
| `profitRate` | 1 | 利润比例（%），计入卖方「我的利润」 |
| `consignUpliftRate` | 3 | 寄售默认价 = 成交价 × (1 + 该比例) |
| `registerDailyLimit` | 300 | 每日自助注册人数上限，0 表示关闭自助注册 |

开始时间必须早于结束时间，不支持跨零点的时段。

## 抢购

- 抢购页展示唯一的「抢购」场次：时段前显示「开馆中 + 距离开始倒计时」，时段内显示「距离结束倒计时」，当天时段结束或没有可抢商品后显示「已闭馆」，次日零点起重新显示「开馆中」。
- **所有商品参与抢购**：平台有库存的商品和其他会员已寄售的商品在同一个列表里；不指定商品时系统随机分配一件平台商品。
- 抢购条件，缺一不可：账号未被暂停；身份资料已通过人工核验（否则提示「请提交身份资料供人工核验」）；当前在抢购时段；本日成功抢到的订单少于 `grabLimit`（否则提示「每人每次只能抢两单」）；燃料费余额不少于本单应扣燃料费。
- 已取消的抢购单不计入限额，并退回已扣燃料费。

## 燃料费与利润

- 「燃料费余额」即原「优惠券」余额。会员线下向上家付款，由管理员在会员管理里「充值燃料费」。
- 抢购成功：买方燃料费 −（成交价 × 2%）；卖方（上一手寄售人）「我的利润」+（成交价 × 1%）。金额均**向下取到分**。
- 价格链示例：1000 →（+3%）1030 →（+3%）1060.90。成交价 1060.90 时燃料费 21.21、利润 10.60；成交价 1030 时燃料费 20.60、利润 10.30。

## 寄售

- 仅在寄售时段内可寄售；价格默认为成交价上浮 3%，按默认价寄售不需要交易密码，改价时需要。
- 会员可在仓库「买方」页点「一键全部寄售」；管理员可在后台「拍卖仓库」点「一键转寄售」，后者不受时段限制。
- 仓库页只保留「买方」「卖方」两个标签。

## 账号

- 会员自助注册（昵称、手机号、密码、可选邀请码），不使用短信。邀请二维码在「业务中心 → 邀请好友」，扫码后自动带出邀请人。
- 管理员可「暂停账号」：被暂停账号立即无法登录，已登录的会话同时失效；「恢复账号」后可正常使用。
- 收款管理支持银行卡、微信、支付宝（含收款二维码图片），保存时需输入交易密码。

## 对账报表

后台「账户流水 → 对账报表」按日汇总每位会员，可导出 Excel：

- 前日买单、当日卖单、当日买单；
- 差额 = 当日卖单 − 当日买单；
- 实际收付 = 差额 − 当日买单 × 燃料费率（向下取到分）。

上述公式用原表一行数据核对过：卖单 172066.54、买单 221930.63 → 差额 −49864.09，燃料费 4438.61，实际收付 −54302.70。「备注抵扣」列留空，导出后手工填写。

## 实现时的假设（如与实际不符请告知）

1. 会员之间的货款**线下结算**（对应对账报表里的「实际收付」），系统只记账：抢购寄售商品时不要求也不扣减账户余额，只校验并扣除燃料费。
2. 平台商品的首单仍走原有「待付款 → 上传凭证/余额支付 → 审核」流程。
3. 抢购日按北京时间自然日计算；「每人每次」即每个抢购日。
4. 「积分余额」改称「我的利润」，数值取原积分字段；利润记录同时出现在「我的利润」页。

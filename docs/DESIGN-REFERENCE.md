# 原站界面记录

目标是忠实恢复已有移动商城，所有视觉选择以原站发布代码为准，不对既有风格做重新设计。

- 主导航：首页、抢购、仓库、我的，底部固定四栏，选中态红色。
- 首页：珊瑚红顶部与轮播、公告栏、甄选新品及更多商品的纵向列表。
- 商品详情：方形商品主图、红色价格、库存和邮费、评价与详情区、底部购买按钮、规格抽屉。
- 个人中心：珊瑚红头像区、订单状态区、积分余额与优惠券双栏、多组功能入口。
- 登录页：浅蓝底、较大欢迎文字、白色输入卡片、蓝青渐变圆角按钮。
- 普通内容页面使用原有 uni-app 默认字体、rpx 换算与安全区域处理。
- 主要对比视口：390 × 844；原站桌面布局会横向铺满，不另外添加手机外框。

原始样式包含白底、渐变和列表卡片等设计，按用户一比一还原要求保留。

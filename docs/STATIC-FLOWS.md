# 静态数据版页面与流程

独立静态版：`npm run build:h5 && npm run preview`，访问 `http://localhost:5175/`。HBuilderX 发行方式见 [打包说明](BUILD.md)。

Node 接口版：`npm run build && npm run dev`，访问 `http://localhost:5173/h5/h5.html#/`。两种模式复用相同业务规则，数据分别保存在浏览器 localStorage 与 `.local/data.json`；互不影响。静态版图片凭证最大 2MB，保存在浏览器内，不上传远端。

## 模拟规则

1. 微信/支付宝支付只更新演示订单，不连接真实收银台。余额支付扣本地余额，积分支付扣本地积分。
2. 订单付款后即时模拟发货，上传充值/付款凭证后即时模拟审核通过。样本中仍保留各中间状态用于展示。
3. 重复付款、充值凭证、确认收款或上架操作不会重复扣款/入账。地址、库存、余额、积分、验证码等错误有对应提示。
4. 竞价拍卖出价阶段只记录竞价，不冻结余额；场次结束后最高价者生成唯一待付款仓库结算单，竞价结算单不可普通取消，再沿用现有付款凭证/支付流程。正式上线需补充保证金、数据库事务锁和并发竞价策略。
5. 转赠给另一已注册本地账号会同步入账；其他手机号作为演示收件人记录。
6. 团队成员、历史提现记录及收益为静态样本，不代表真实分销业绩。提现页在原包中只有历史记录展示，没有提现提交表单。
7. 静态版本没有运营后台、真正短信/支付/物流/实名服务。页面操作的模拟状态保留于本机。

所有原路由与源文件见 `PAGES.md`；开发文件位于 `src/pages`，构建后在 `dist/h5` 运行。恢复工具 `npm run recover` 会覆盖手动修复，不要作为日常构建命令运行。
